# Java `if` Exercise

## Description

Create a Java program that reads 3 student grades and calculates the average.

After calculating the average:

- If the average is greater than or equal to `5`, the student passed.
- If the average is lower than `5`, the student failed.

---

# Requirements

- Use `Scanner` to read the grades.
- Store the grades in variables.
- Calculate the average.
- Use `if` and `else` to check the result.
- Show the final average and the student's status.

---

# Example Output

```text
Enter the first grade: 7
Enter the second grade: 5
Enter the third grade: 6

Average: 6.0
Student passed.
```
