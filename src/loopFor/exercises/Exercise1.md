# Java `for` Exercise - Multiplication Table

## Description

Create a Java program that asks the user for a number and prints its multiplication table (from 1 to 10).

---

# Requirements

- Use `Scanner` to read the number.
- Use a `for` loop to calculate and print the table.
- Show each line in the format: `number x i = result`.

---

# Example Output

```text
Enter a number: 5

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```
