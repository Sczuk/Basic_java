
# Java `for` Exercise - Sum of a Range

## Description

Create a Java program that asks the user for two numbers: a starting number and an ending number.

The program must use a `for` loop to calculate the sum of all numbers within that range (including both the starting and ending numbers).

---

# Requirements

- Create a variable `total` to store the sum.
- Use `Scanner` to read the starting and ending numbers.
- Use a `for` loop to go through the range and add each number to `total`.
- Show the final result with `System.out.println()`.

---

# Example Output

```text
Enter the starting number: 1
Enter the ending number: 5

Sum from 1 to 5: 15
```
