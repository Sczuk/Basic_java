# Java Variables Summary

## What is a Variable?

A variable is something that stores a value so this data can be used later in the program.

Example:

```java
int age = 20;
```

In this example:
- `int` → variable type
- `age` → variable name
- `20` → variable value

---

## Variable Structure

The basic structure of a variable is:

```java
type variableName = value;
```

Example:

```java
String name = "John";
```

---

# Most Common Variable Types in Java

## `boolean`

Stores only `true` or `false`.

```java
boolean isOnline = true;
```

---

## `int`

Stores integer numbers.

```java
int age = 18;
```

---

## `double`

Stores decimal numbers.

```java
double price = 19.99;
```

---

## `String`

Stores text.

```java
String name = "Maria";
```

---

## `char`

Stores a single character.

```java
char letter = 'A';
```

---

# Other Variable Types

These types are less commonly used but are also available in Java.

## `short`

Stores smaller integer numbers.

```java
short number = 100;
```

---

## `long`

Stores very large integer numbers.

```java
long population = 8000000L;
```

---

## `float`

Stores decimal numbers with less precision than `double`.

```java
float height = 1.75f;
```

---

## Conclusion

Variables are essential in Java because they allow data to be stored and reused throughout the program.
Choosing the correct variable type helps organize the code and improves performance.
