# Java Variables Exercise

## Description

Create a Java program that asks the user for two numbers and performs:

- Sum
- Subtraction
- Multiplication
- Division

## Rules

- Create 4 varibles:
    - `totalSum`
    - `totalSubtract`
    - `totalMultiply`
    - `totalDivide`
- Use `Scanner` to read the numbers.
- Use `System.out.println()` to show the results.

## Example

```text
Enter the first number: 8
Enter the second number: 2

Sum: 10
Subtraction: 6
Multiplication: 16
Division: 4
